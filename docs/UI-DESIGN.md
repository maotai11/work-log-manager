# UI/UX 設計規範

## 設計原則

1. **簡潔直覺** - 減少學習成本，一眼即懂
2. **資訊層次** - 重要資訊優先，次要資訊收斂
3. **即時反饋** - 每個操作都有視覺回應
4. **一致性** - 統一的視覺語言與互動模式

## 互動規範

### 按鈕狀態
```
Default:    背景色 + 文字色
Hover:      加深 10% 背景
Active:     加深 20% 背景
Disabled:   50% 透明度
Focus:      ring-2 ring-offset-2
```

### 輸入框
```
Default:    border-gray-200
Focus:      ring-2 ring-{color}-500 border-transparent
Error:      ring-2 ring-red-500 border-red-500
```

### 卡片懸停
```css
transition-all duration-200
hover:border-{color}-300
hover:shadow-md
```

### 載入狀態
```
Spinner: 圓形旋轉動畫
Skeleton: 漸層閃爍效果
Saving: 脈動綠點 + "儲存中..."
```

### 成功/錯誤反饋
```
Success: 綠色背景 toast
Error: 紅色背景 toast
自動消失: 3秒
```

## 動畫曲線

```css
/* 標準緩動 */
transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1);

/* 進入動畫 */
transition-timing-function: cubic-bezier(0, 0, 0.2, 1);

/* 離開動畫 */
transition-timing-function: cubic-bezier(0.4, 0, 1, 1);
```

### 動畫持續時間
```
快速: 150ms (hover 效果)
標準: 200ms (大多數過渡)
較慢: 300ms (模態框進出)
```
